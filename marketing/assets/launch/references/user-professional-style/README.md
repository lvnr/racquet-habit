# User-supplied professional photography references

These images are visual and art-direction references only. They must not be used as sources for people, garment designs, logos, text, or exact scene replication.

Useful traits:

- graphic court geometry and intentional negative space
- strong natural or hard-sun shadow design
- professional fashion-editorial posing
- foreground framing through a racquet or net
- controlled color and skin tones
- clean garment presentation
- low and unexpected camera angles
- occasional studio restraint

Do not import:

- third-party brand marks
- reference garment graphics
- visible interface chrome or watermarks
- uncanny skin smoothing
- implausible athletic poses
